# Mini Message Board 📬

A lightweight full-stack message board built from scratch to learn web architecture.

## 🛠️ Tech Stack
- **Frontend:** Plain HTML, CSS, JavaScript (`fetch()` API)
- **Backend:** Node.js & Express
- **Storage:** In-memory JavaScript array
- **Architecture:** REST API endpoints (`GET /api/messages`, `POST /api/messages`)

## 🚀 Running Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   node server.js
   ```
3. Open your browser at:
   `http://localhost:3000`
